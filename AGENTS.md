# AGENTS

## Instrução de projeto

Os PRDs devem ser sempre criados na raiz do projeto atual, seguindo o formato:

`docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`

## Regras

- Sempre criar o PRD na raiz do projeto.
- Respeitar exatamente o formato de caminho e nome acima.
- Usar a data atual no formato `YYYY-MM-DD`.
- Usar uma descrição curta e clara, em minúsculas, substituindo espaços por hífens.
- Garantir que o arquivo final fique dentro do diretório `docs/plans/`.
