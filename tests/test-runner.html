Também no terminal

A suíte Node verifica regras puras, integridade da página e sintaxe. O painel complementa essa cobertura com interações de navegador.

npm test

Para abrir este painel

Sirva o projeto pela raiz para permitir que o navegador importe o módulo de regras.

python3 -m http.server 8000 /tests/test-runner.html

Cobertura desta página

  • +Normalização, letras duplicadas e tamanho do vocabulário diário.
  • +Entrada inválida, progresso após recarga, vitória e compartilhamento sem resposta.
  • !Não substitui testes com leitor de tela, auditoria WCAG ou revisão editorial humana.
